# NPC Life 同步世界

版本：`3.3.3-sync`

目标环境：SillyTavern `1.17.0`

NPC Life 是一个纯前端扩展：按角色卡隔离世界，记录已追踪 NPC 的活动资料与可发现痕迹，在正文结束后结算，下一轮按当前场景注入。地点只作软约束；异地偶遇是低概率的“可能路过”机会，不计算地图或路线。

## 安装

把本仓库安装到：

```text
public/scripts/extensions/third-party/npc-life/
```

安装地址保持不变：

```text
https://github.com/muzi9277/npc-life
```

更新后执行 `Ctrl+F5`。运行文件为 `manifest.json`、`index.js`、`style.css`、`console.js`、`console.css`、`services.js`、`automation.js`、`timeline.js`、`world-service.js`、`activity-ledger.js`、`living-world.js`。

## 当前能力

- NPC 活动资料库：保存做过、正在做、准备做的已提交活动。
- 痕迹延迟发现：确实会留下可观察物证的行动才生成痕迹；玩家后续调查或进入相关场景时才提供线索机会。
- 发现写回：只有玩家视角实际写出发现才记为已发现；NPC 自己发现、调查提问、路过和偶遇不会记成玩家已知。
- 每轮正文结束后结算；本轮新结果最早下一轮生效。正文没写经过时间按0分钟。
- 动态世界书、公开世界状态重合、低概率偶遇和地点软权重。
- 多人卡按角色卡隔离；只自动追踪已出场且有设定的人，以及用户明确指定的人。锁定只保留状态，不冻结行为。
- 记忆增强插件只读参考，默认不写回；旧格式插件自身可能存在迁移副作用，不能承诺绝对零写入。
- 主API使用 `generateRaw`，不使用 `generateQuietPrompt`。

## 边界

插件不做完整地图、坐标、路线或旅行时间计算，不把后台提案当正史，不保证主模型一定采纳提示。记忆读取、供应商预算、模型剧情自然度和真实酒馆行为需要按本机配置实测。

完整 beta.7 自动版保留在 `legacy/beta7-auto/` 与历史标签中；旧设置键保持兼容。

## 测试

仓库历史中的测试使用合成数据与mock，不调用真实付费API。发布前需在本机SillyTavern中执行最小连续场景：NPC行动→痕迹积累→玩家延迟调查→发现写回→编辑来源后撤回。
